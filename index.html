Belum dikonfigurasi

Fitur cloud memerlukan proyek Firebase milik organisasi. HTML saja tidak dapat membuat database internet bersama secara otomatis. Setelah konfigurasi diisi dan aturan keamanan dipasang, anggota yang login ke proyek yang sama dapat membaca dan menulis transaksi secara real-time.

Langkah aktivasi cloud: 1) Buat proyek di Firebase Console. 2) Aktifkan Authentication → Email/Password dan buat akun untuk pengurus. 3) Buat Firestore Database. 4) Pasang aturan Firestore yang membatasi akses ke anggota terdaftar. 5) Isi konfigurasi aplikasi web di atas. 6) Hosting file ini pada layanan HTTPS (misalnya Firebase Hosting). Jangan gunakan database dengan aturan baca/tulis publik. API key Firebase bukan kata sandi, tetapi akses database tetap harus dilindungi Authentication dan Security Rules.

Belum terhubung. Mode lokal tetap bisa digunakan; data lokal tidak otomatis berpindah ke perangkat lain.
